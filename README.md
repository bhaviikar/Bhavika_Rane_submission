 Project Overview
This project focuses on evaluating the user experience of selected applications through user interviews, Think Aloud sessions, and practical research exercises. The objective is to identify usability problems, understand user needs, and propose improvements to the overall user experience.

Final Conclusion Summary
The research findings highlight usability challenges and opportunities to improve navigation, information discovery, interface clarity, and user interactions. The proposed redesign uses these findings to make the application experience clearer and more effective for users.
